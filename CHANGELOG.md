# ToutPVR 1.0.0-dev.2

Téléchargement depuis repo.qu3ntin.com (GitLab, GitHub en secours) avec --channel ; mot de passe 10 caractères minimum.

## [1.0.0]
- Première version : serveur NVR avec panneau web Aurora Glass en 20 langues.
- Caméras RTSP, ONVIF, USB ; enregistrement continu ou sur événement ; zones et lignes de franchissement.
- Détection par IA : mouvement, personnes, véhicules, animaux, et analyse par modèle de vision local (Ollama).
- Utilisateurs, grades et permissions, double authentification, clés API, journal d'audit.
- Licence Ed25519 avec tolérance hors ligne, mises à jour signées avec retour arrière.
- Installeurs Linux (toutes distributions, AlmaLinux 10 inclus), Windows et Docker.
